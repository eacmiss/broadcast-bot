# 📢 Broadcast Messenger Bot

Telegram бот для массовых рассылок сообщений в сообществах и чатах.

## ✨ Возможности

- **Массовые рассылки** - Отправка сообщений всем пользователям бота
- **Админ-панель** - Управление рассылками
- **Статистика** - Отслеживание отправленных сообщений
- **Список пользователей** - Просмотр базы пользователей
- **Поддержка HTML** - Форматирование сообщений

## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd broadcast-bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env`:
```bash
cp .env.example .env
```

4. Добавьте настройки в `.env`:
```
TELEGRAM_BOT_TOKEN=your_bot_token_here
ADMIN_USER_IDS=123456789,987654321
```

**Важно:** `ADMIN_USER_IDS` - список ID администраторов через запятую

## 🚀 Запуск

### Локально (polling):
```bash
python src/bot.py
```

### На Vercel (webhook):
1. Разверните на Vercel
2. Установите webhook:
```bash
curl -F "url=https://your-app.vercel.app/api/webhook" https://api.telegram.org/bot<YOUR_TOKEN>/setWebhook
```

## 👨‍💻 Как узнать свой Telegram ID

1. Откройте бота @userinfobot
2. Отправьте любое сообщение
3. Бот вернёт ваш ID

## 📊 Использование

### Для пользователей:
1. Запустите бота командой `/start`
2. Вы автоматически добавитесь в базу для рассылок

### Для администраторов:
1. Запустите бота командой `/start`
2. Нажмите "📢 Админ-панель"
3. Выберите "📨 Отправить рассылку"
4. Напишите сообщение для рассылки

## ⚠️ Ограничения

- Telegram имеет лимиты на массовые рассылки (рекомендуется не более 30 сообщений в секунду)
- Пользователи могут заблокировать бота - их сообщения не будут доставлены

## 🔒 Безопасность

- Только администраторы могут отправлять рассылки
- ID администраторов хранятся в переменных окружения
- База данных хранится локально
